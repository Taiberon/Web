# Техническое задание на разработку информационного сайта



## 1.1 Тема информационного ресурса



Тема информационного ресурса — **«пока пусто»**.



Цель сайта — предоставить информацию на сопутствующую тему в структурированном формате.



## 1.2 Краткое ТЗ



### Структура сайта



Информационный ресурс должен содержать **пока не ясно сколько страниц**:



1. **Главная страница**



### 1. Главная страница



На главной странице размещаются:



* название сайта;
* навигационное меню;
* Тема информационного ресурса и краткое описание;
* изображения на сопутствующую тему;
* ссылки на остальные разделы сайта (при необходимости);
* Футер.

Функциональные возможности:

* переход между разделами сайта;

* переход к отдельным материалам;

* возврат на главную страницу.

## Общие требования к сайту

Сайт должен иметь:

* единый стиль оформления всех страниц;

* удобное и понятное навигационное меню;

* читаемый текст;

* логичную структуру размещения информации;

* изображения и графические элементы;

* адаптацию под различные размеры экрана;

* единое оформление заголовков, текста и кнопок.

Файлы проекта должны быть организованы следующим образом:

```

Название\_сайта/

  CSS/

  images/

  fonts/

  HTML-файлы

```
